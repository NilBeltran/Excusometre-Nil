**Control i verificació de les justificacions dels estudiants**

¿Que fem?

Verifiquem les justificacions acadèmiques mitjançant tecnologia d’última generació, capaç d’identificar possibles irregularitats i determinar-ne la fiabilitat.

¿Com funciona?

Rebem les justificacions potencialment fraudulentes i les analitzem de manera detallada. Posteriorment, identifiquem les que presenten indicis d’irregularitat i, finalment, les sotmetem a un sistema de revisió virtual que emet una resolució final.

Estat del "Sistem" of the Machine

Sistema de control i prevenció d’excuses (ANTI-EXCUSES), sempre preparat i operatiu!
